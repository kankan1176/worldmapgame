# BORDERLINE — 国境をつなぐ旅

国名・国旗・国の輪郭を手掛かりに陸路で目的地を目指す3つの経路モードと、別画面の「世界領土クイズ」「言葉遊びモード」を備えたブラウザゲームです。

## 遊ぶ

GitHub Pages の公開設定が完了すると、次のURLで遊べます。

https://kankan1176.github.io/worldmapgame/

`index.html` をダウンロードしてブラウザで直接開いても遊べます。画像・データを含む単一HTMLで、インストールやビルドは不要です。

## 操作

- トップ画面で国名・国旗・輪郭・世界領土クイズ・言葉遊びの5モードから選択。
- 隣接する国名を入力し、矢印ボタンで移動。
- 入力候補から国名を選択可能。ひらがな・カタカナ・英語・国コードに対応。
- 地図をドラッグして移動、ホイールまたは＋／−で拡大縮小。
- スマホでは指で地図を移動し、2本指で拡大縮小。
- 目的地に到達すると、最短経路と移動回数を比較。

スクロールなしの画面構成で、長い経路や説明はページ送りで表示します。

## 公開設定（初回）

GitHub の Settings → Pages → Build and deployment で次を指定します。

- Source: GitHub Actions

`.github/workflows/pages.yml` が main ブランチへの保存時に自動でゲームを公開します。Actions 画面から手動実行することもできます。公開処理の完了後、上記URLが有効になります。

## 難易度の設定

経路3モードでは、次のルールをそれぞれオン／オフできます。トップ画面で設定するか、プレイ画面の「設定」から変更してください。設定を保存すると新しい問題でリスタートします。設定は同じブラウザに保存されます。

- 経由国指定：自動で指定された国を通る。
- 通行禁止：自動で指定された国へは入れない。
- 最短回数：指定条件を満たす最短ルートだけが成功。途中の国数は出発国と目的国を除く通過回数です。同じ国を再び通る場合も数えます。

出題時・ヒント・採点で、同じ経由国と通行禁止国を考慮します。

## 世界領土クイズ

「いま」「むかし」「まぜる」から選ぶ4択クイズです。日本などの島や海外領土の現在の所属、所属が変わったきっかけ、条約・協定の内容など110問（「いま」60問・「むかし」50問）を収録しています。どの時代を選んでも、1回の旅は10問。同じ回では問題が重複しないようランダムに選びます。子どもにも読みやすい言葉と漢字のルビで説明し、各問の回答後に政府機関・公的機関の出典リンクを表示します。正解は緑、不正解は赤と記号で表示します。

年号だけを答える問題はありません。「いま」は現在の所属・自治など60問、「むかし」は条約・協定の内容20問、返還・購入・独立・判決などのきっかけ16問、昔の所属14問です。年は問題の時点を示す手掛かりとして使い、答えは国・地域・できごと・約束の内容から選びます。

`quiz-master.json` は110問の問題文・4択・正解・解説・場所・出典をまとめたマスタのスナップショットです。ゲーム本体は同じデータを `index.html` 内に収録しているため、JSONだけの変更はゲームには反映されません。更新時は両方を合わせて更新してください。

クイズの地図は現在の概略図で、問題の場所を示すものです。歴史上の国境を復元した地図ではありません。自治・領土・州・独立国・かつての統治は、問題の時点と表現に従って区別しています。

## 言葉遊びモード

国名の文字の条件に合う国を地図から選びます。データ内の独立国194か国のカタカナ表記を使い、306種類の条件から出題します。条件に合う国が複数ある場合は、どれを選んでも正解です。

| レベル | 出題 | 正解の得点 |
| --- | --- | --- |
| 1 | 指定の頭文字で始まる国 | 1pt |
| 2 | 指定の文字で始まり、指定の文字で終わる国 | 3pt |
| 3 | 〇で隠した国名を濁点・半濁点・長音などから推理 | 5pt |

1回10問（レベル1が4問、レベル2・3が各3問）、満点28ptです。誤答・パスは0pt。地図をタップして国を選び、「この国で答える」で確定します。ドラッグ・ピンチで地図を動かしただけでは回答しません。地域選択、＋／−、全体表示が使え、小さな国の近くをタップすると近隣の候補も選べます。

日本は「ニホン」、中国は「チュウゴク」、UAEは「アラブシュチョウコクレンポウ」など、出題表記を定めています。小さい文字も1文字。「カ」と「ガ」は区別します。頭文字・末尾の判定では中点を除外し、長音は文字として扱います。マスクでは〇が1文字で、゛・゜・ー・中点を残します。

10問を終えたスコアの上位100件をブラウザのlocalStorageへ保存し、自分のランキングとして得点順・正解数順・新しい記録順で表示します。同じ端末・同じブラウザ内の記録で、閲覧データを消すと消えます。アカウントや他の端末との同期はありません。保存が利用できない場合は、ページを開いている間の記録を表示します。

## スマホの操作と表示

5モードの選択、ゲーム、結果、ランキングはページスクロールなしで表示します。地図は1本指で移動、2本指で拡大縮小。言葉遊びではタップとドラッグを区別し、回答ボタンを画面下にまとめています。経路モードの出題範囲は「設定」にあり、保存するとリスタートし、キャンセルでは進行中の旅を変更しません。領土クイズの横画面では「地図を見る」で問題と場所を切り替え、回答後は解説を中心に表示します。

## 国境ルールとデータ

- 国名・国旗・隣接関係: [mledoze/countries](https://github.com/mledoze/countries)（ODbL-1.0）。データ取得日: 2026-10-15。
- 地図・輪郭: [datasets/geo-countries](https://github.com/datasets/geo-countries)、Natural Earth。
- 加工した国・地域データは `index.html` 内の `ATLAS` 定数に、国旗は `FLAGS` 定数に収録しています。元データのライセンスは各出典に従います。
- 陸路が成立する国のみ出題します。海峡・航路は接続に含めません。
- 海外領土から宗主国への自動移動はありません。フランスとブラジル・スリナムの直接接続は除外しています。
- 輪郭は最大の陸地を表示し、すべての島・領土を表すものではありません。
- 区分や国境はゲームデータ上の定義で、政治的立場を示しません。
